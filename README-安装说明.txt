学术猫·论文工作台｜iPhone Web App V3 完整升级版

【V3 本次一并升级】
1. 统计：今日 / 本周 / 本月 / 本年 / 全部五级统计。
2. 写作日历：月历热力图，点某一天查看字数、时长、问题、修改、待办、导师会议等单日详情。
3. 进度预测：根据近14日真实写作速度预测达到总字数目标的日期，并与提交日期比较。
4. 论文健康度：首页显示逾期待办、高优先级未闭环、写作速度和进度风险。
5. 全局搜索：跨章节、小节、问题、文献、修改、待办、会议、图表、版本和答辩内容搜索。
6. 章节升级：章下面可继续建立小节，分别记录目标字数、当前字数、状态和备注。
7. 写作记录升级：可指定到具体小节；支持编辑、删除，并自动调整章节/小节累计字数。
8. 问题/答疑升级：增加来源、依据资料、解决日期、复盘总结、平均解决天数和重新打开问题。
9. 文献升级：语言、文献类型、标签、重点收藏、阅读状态、可用于章节、引用格式与核心观点。
10. 修改跟踪升级：增加修改轮次，适合导师多轮修改、预答辩、盲审和正式答辩意见。
11. 待办升级：截止日期、逾期提示、优先级和首页紧急事项汇总。
12. 导师会议：独立记录每次沟通日期、会议要点、导师原话、明确下一步行动和下次沟通日期。
13. 图表清单升级：除完成状态外，单独检查图题/表题、正文引用、来源/注释。
14. 时间节点：初稿、送审、预答辩、答辩、定稿等关键日期。
15. 版本管理升级：保存版本时自动快照当时累计字数，并可记录文件名/文件位置和本版变化。
16. 定稿检查清单：内置封面、摘要、目录、章节、图表、公式、参考文献、格式、PDF逐页检查、异地备份等项目；支持自定义。
17. 答辩准备升级：PPT、陈述、可能提问、回答要点、材料清单、模拟答辩，并增加1-5熟悉度。
18. 数据导出：JSON 完整备份 + CSV 汇总导出。
19. 历史快照：自动/手动本地快照，最多保留最近6份，可误删恢复。
20. iPhone/PWA：继续支持主屏幕图标、安全区、独立打开和离线缓存。

【推荐新建独立 GitHub 仓库】
仓库名：thesis-workbench
把本 ZIP 解压后的全部文件上传到仓库根目录。
Settings → Pages → Deploy from a branch → main → / (root) → Save。

【数据安全】
GitHub Pages 只保存程序代码，不保存你的论文记录。记录默认保存在 iPhone 当前网页 App 的本地存储。
本地快照只是防误删，仍建议定期导出 JSON 到“文件”或 iCloud Drive。
