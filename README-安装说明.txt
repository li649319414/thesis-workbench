学术猫·论文工作台｜iPhone Web App 完整版 V1

【包含功能】
1. 首页总览：总字数、今日字数、连续写作、答辩倒计时、最近动态
2. 章节进度：自定义章节、目标字数、当前字数、完成度、备注
3. 专注写作：25 分钟计时（可在设置修改），完成后登记字数和时间
4. 问题记录 / 答疑：问题描述、类型、章节、状态、处理过程、解决结果、经验总结
5. 导师意见 / 修改跟踪：来源、优先级、状态、修改说明
6. 文献卡片：作者、年份、阅读状态、可用于章节、引用格式、核心观点
7. 图表清单：图号/表号、名称、章节、完成状态、备注
8. 时间节点：初稿、送审、预答辩、答辩、定稿等
9. 统计总览：字数、专注次数、问题、已解决问题、文献、修改、图表、连续写作
10. JSON 导出/导入备份
11. PWA 离线缓存，添加到 iPhone 主屏幕后可独立打开

【上传到你现在的 GitHub 仓库】
你的仓库目前是 kaogong-iphone。最简单的方法：
1. 先在 App 内导出旧版备份（如果旧版已有重要数据）。
2. GitHub 仓库 → Add file → Upload files。
3. 上传本 ZIP 解压后的全部文件到仓库最外层。
4. 同名文件选择覆盖并 Commit changes。
5. 如果仓库里还保留旧的 README 安装说明等，不影响运行。
6. GitHub Pages 继续使用 main / (root) 即可，不需要重新建仓库。

【iPhone 安装】
1. 等 GitHub Pages 更新后，用 Safari 打开网页。
2. 分享 → 添加到主屏幕 → 作为网页 App 打开 → 添加。
3. 如果桌面仍显示旧图标，先删旧主屏幕图标，再从 Safari 重新添加。

【数据说明】
所有写作记录、问题、导师意见、文献等默认保存在当前 iPhone 的浏览器本地存储中，
GitHub Pages 只保存程序文件，不保存你的论文数据。
请定期使用“导出备份”保存 JSON 文件。
