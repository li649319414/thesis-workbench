学术猫·论文工作台｜iPhone Web App V5

V5 新增独立一级模块【成果】，用于管理“已经搜集到什么、已经处理了什么、已经分析出什么、最终做出了哪些图表”。

【成果模块】
1. 数据资产
- DEM、遥感影像/DOM、地质资料、灾害点/隐患点、降雨、道路、水系、人口、土地利用/植被、实验/监测/统计数据等。
- 来源、日期、格式、分辨率/比例尺、坐标系、覆盖范围、质量、文件位置、所属章节、是否已入文。
- 尚未拿到的数据也可以先建成“待搜集”，自动成为数据缺口清单。

2. 数据处理
- 清洗、投影、裁剪、重采样、配准、矢量化、因子提取、距离分析、栅格运算、样本构建、统计分析、模型训练、精度检验、制图等。
- 输入数据、软件、处理步骤、关键参数、输出结果、质量、结果文件位置、是否可复现、是否已入文。
- 状态：待处理 / 处理中 / 已完成 / 已核验 / 已入文 / 需重做。

3. 分析 / 模型
- 统计分析、信息量模型、随机森林、耦合模型、AHP、ROC/AUC、情景分析、稳定性计算、数值模拟、敏感性分析等。
- 输入、方法、参数、版本、关键指标、主要结果、质量核验、结果文件和论文使用状态。

4. 图表成果
- 图/表编号、标题、所属章节、依据数据/处理结果、最终文件位置。
- 单独检查图题/表题、正文引用、来源/注释。
- 原来“资料”里的图表已归入“成果”，避免逻辑重复。

5. 成果总览
- 已获取数据、已完成处理、已完成分析、已完成图表、已入文成果、待核验、需更新/重做。
- 研究链条：数据 → 处理 → 分析 → 图表/入文。
- 自动生成章节证据矩阵：每一章当前已有多少数据、处理、分析和图表支撑。

【联动升级】
- 首页增加“研究成果”快捷入口。
- 最近动态加入数据/处理/分析更新。
- “全部统计”新增研究成果累计统计。
- 全局搜索可以搜索数据、处理、分析和图表。
- CSV 导出包含研究成果记录。
- V5 自动兼容 V4 / V3 / V2 / V1 的本地数据。

【信息架构】
首页 / 章节 / 问题 / 成果 / 资料 / 统计 / 设置
底部导航可横向滑动。

注意：大体积 TIF、SHP、DEM、影像不会直接存入 Web App。App 保存的是台账、来源、质量、方法参数和文件位置。
建议定期在“设置 → 工具与数据”导出 JSON 备份。
