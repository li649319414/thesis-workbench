学术猫·论文工作台｜iPhone Web App V4

V4 重点调整：
- 底部一级导航改为可横向滑动： 首页 / 章节 / 问题 / 资料 / 统计 / 设置。
- “设置”成为独立一级页面，不再藏在首页。
- 首页删除“工具与数据”，只保留论文推进相关内容。
- 设置页集中管理：论文参数、写作参数、JSON 备份/导入、CSV 导出、历史快照、全局搜索、隐私说明、程序缓存、使用说明、危险操作。
- 论文设置新增：学校、学位类型、当前阶段、每周字数目标、初稿/预答辩/定稿日期、默认写作章节。
- 可选择隐藏首页论文题目、关闭连续写作统计。
- V4 自动兼容并迁移 V3/V2/V1 的本地数据。

推荐 GitHub 仓库：thesis-workbench
解压后将全部文件上传到仓库根目录，GitHub Pages 保持 main / (root)。

重要：论文数据保存在 iPhone 本地。建议定期在“设置 → 工具与数据 → 导出 JSON”备份到 iCloud Drive/电脑。
