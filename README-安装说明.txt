学术猫·论文工作台｜iPhone Web App 全功能版 V2

【V2 已包含完整模块】
1. 首页总览
   - 论文总目标字数、当前累计字数、完成百分比
   - 今日目标、今日已写、连续写作、答辩倒计时
   - 最近动态
2. 专注写作
   - 番茄钟/专注计时
   - 登记本次写作字数、时长、章节、完成内容
   - 自动累计到章节总字数
3. 章节进度
   - 自定义章节
   - 目标字数、当前字数、完成度、状态、备注/待补内容
4. 问题记录 / 答疑闭环
   - 问题标题、所属章节、问题类型、优先级
   - 问题描述、处理过程、最终解决结果、经验总结
   - 未解决 / 处理中 / 已解决 / 需继续跟进
5. 导师意见 / 修改跟踪
   - 导师、自查、盲审、格式规范、答辩意见等来源
   - 优先级、状态、修改说明
6. 日常待办
   - 今天要写什么、补什么、改什么
   - 所属章节、优先级、截止日期、完成状态
7. 文献卡片
   - 文献标题、作者、年份、阅读状态
   - 可用于章节、引用格式/DOI/链接、核心观点
8. 图表清单
   - 图/表类型、编号、名称、所属章节
   - 待制作/制作中/待核对/已完成
9. 时间节点
   - 初稿、送审、预答辩、答辩、定稿等
10. 论文版本管理
   - 章节稿、初稿、导师修改稿、预答辩稿、送审稿、答辩稿、定稿
   - 每个版本记录日期和主要变化
11. 答辩准备
   - 答辩PPT、自我陈述、可能提问、回答要点、材料清单、模拟答辩
12. 统计总览
   - 本周写作字数
   - 本月写作趋势
   - 累计字数、专注次数、专注时长
   - 问题总数、已解决问题、问题类型分布
   - 文献数、已完成修改、已完成待办、已完成图表
   - 版本数、答辩准备完成数、连续写作天数
   - 各章节完成度
13. 本地数据与备份
   - 数据默认只保存在当前 iPhone 浏览器/PWA 本地
   - JSON 导出 / 导入备份
14. iPhone PWA
   - 主屏幕图标使用用户指定猫图
   - iPhone 安全区适配
   - 独立 Web App 打开
   - Service Worker 离线缓存

【建议使用独立 GitHub 仓库】
推荐仓库名：thesis-workbench
上传本 ZIP 解压后的全部文件到仓库根目录，然后：
Settings → Pages → Deploy from a branch → main → / (root) → Save

【注意】
V2 使用新的本地存储键 academicCatThesisWorkbenchV2。
如果你之前已经在 V1 录入了真实论文数据，请先从 V1 导出 JSON 备份，再在 V2 中导入。
