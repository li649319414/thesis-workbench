学术猫·论文工作台｜iPhone Web App V6.6

【本版定位】
V6.6 是“稳定性 + 交互 + 数据安全”总升级版。在 V6.5 五导航基础上，重点改造本地数据库、图片存储、离线启动、快照、回收站和长期使用体验。

【V6.6 主要新增】
1. IndexedDB 主数据库
- 主论文数据优先写入 IndexedDB。
- localStorage 仅保留兼容镜像，便于异常时回退。
- 第一次打开 V6.6 时，自动读取 V6.5 / V6.4 / 更早数据。
- 迁移前自动创建快照，并对主要数据集合数量进行迁移校验。
- 不主动删除旧版 V6.5 数据。

2. IndexedDB 图片资料库
- 可在“资料 → 资料 → 图片库”保存图片。
- 图表记录可直接选择多张本地图片并与图表关联。
- 图片 Blob 原文件保存于 IndexedDB，不写入 localStorage，不上传 GitHub Pages。
- 适合保存结果图、图件预览、文献截图、导师修改截图等。

3. 自动快照
- 每 6 小时最多自动创建 1 份状态快照。
- 手动导入、程序更新、版本迁移等关键操作前会自动创建保护快照。
- 最多保留最近 12 份。

4. 回收站
- 删除章节、写作记录、小节、章节任务、文献、待办、问题、修改、图表等内容时先进入回收站。
- 删除后底部提供短时间“撤销”。
- 回收站支持恢复和永久删除。
- 写作记录恢复时会同步恢复章节 / 小节字数。
- 回收站项目保留 30 天后自动清理。

5. 离线优先与更新保护
- App 核心程序文件采用 Cache First / 后台刷新策略。
- 第一次完整加载并添加到 iPhone 主屏幕后，无网仍可打开和记录。
- 联网后后台检查程序更新。
- 发现新版本后显示“发现新版本”，点“备份并更新”会先自动创建快照再更新。

6. 资料页面重新分组
- 资料：文献 / 图表 / 图片库
- 执行：待办 / 导师修改 / 导师会议 / 时间节点
- 交付：版本 / 送审 / 答辩
- 支持进行中 / 已完成筛选，并加入部分排序选项。
- 长列表按批次加载，降低大量记录时的页面压力。

7. 写作台优化
- 章节改为折叠树形结构。
- 展开章节即可直接查看和编辑小节、章节任务。
- 写作登记会记住上一次选择的章节和小节。

8. 统计优化
- 默认使用简洁模式，先看核心指标和趋势。
- 可点“展开详细”查看日历、历史周/月、完整记录和下钻数据。

9. 统一快速新增
- 右下角“+”统一打开快速新增菜单：写作记录 / 问题 / 待办 / 文献 / 导师修改 / 导师会议。

10. 全局搜索升级
- 搜索章节、小节、章节任务、写作路线、问题、文献、修改、待办、会议、图表、版本、答辩。
- 同时搜索 IndexedDB 图片名称和关联信息。
- 结果标注来源并可直接进入对应记录。

11. iPhone 交互优化
- 页面切换记住上次滚动位置。
- 键盘弹出时自动隐藏底部导航和悬浮按钮。
- 表单底部保存操作保持在更容易点击的位置。
- 页面列表使用 content-visibility 和分批显示改善长列表性能。

12. 页面顶栏简介
- 顶栏标题下不再统一显示“极简猫系界面 · 写作、记录、统计一体化”。
- 首页、写作台、问题、专注、资料、统计、我的分别显示对应页面功能简介。

【五个底部导航】
首页 / 写作台 / 资料 / 统计 / 我的

【数据安全说明】
- IndexedDB、自动快照和回收站都属于 iPhone / 浏览器本机数据，并不是 iCloud 云同步。
- 清理 Safari 网站数据、删除站点数据、系统清理等操作仍可能造成丢失。
- 建议定期使用“我的 → 导出 JSON”备份到 iCloud Drive 或电脑。
- JSON 主要备份论文结构和文字记录；IndexedDB 图片建议原始文件仍保留在相册、iCloud Drive 或电脑中。

【安装 / 替换】
1. 解压压缩包。
2. 将全部文件上传并覆盖 GitHub Pages 仓库根目录文件。
3. iPhone 打开原“学术猫”App。
4. V6.6 会自动迁移 V6.5 数据到 IndexedDB，并保留旧版兼容数据。
5. 如果仍显示旧页面，可进入“我的 → 重建离线缓存”，或在 Safari 打开网页后重新载入。

重要：首次加载 / 更新程序需要联网；完成首次缓存后，日常记录与大部分功能可离线使用。
