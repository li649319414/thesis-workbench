学术猫·论文工作台｜iPhone Web App V6.3

V6.3 统计分析增强：
- 保留 V6.1 的统计日历布局修复，日历不会再把页面横向撑开。
- 新增“目标完成情况”：单日、每周、每月、年度和总览均自动计算目标完成率、已完成字数与剩余字数。
- 新增“环比变化”：单日对比前一天、每周对比上一周、每月对比上个月、年度对比上一年，显示写作字数、专注时长和写作会话变化。
- 新增“写作效率”：自动统计平均每次写作字数、平均每小时字数、平均每次写作时长和周期内最高产的一天。
- 新增“问题与修改闭环”：统计本周期新增/解决问题、新增/完成导师修改，并显示当前未闭环数量和平均闭环耗时。
- 新增“章节进度”：展示各章当前字数/目标字数、完成率，并标注当前所选周期内该章新增字数；点击可直接进入章节详情。
- 所有新增分析会随“单日 / 每周 / 每月 / 年度 / 总览”和历史日期自动变化。

V6/V6.1 原有功能继续保留：
- 秒级记录创建/修改时间，业务日期单独保存。
- 历史周、历史月、年度和累计总览。
- 月份内可继续选择具体周查看。
- 统计日历支持点击某天查看当天详细记录。
- 底部导航合并为：首页 / 写作台 / 记录 / 我的。
- 写作台整合章节管理、问题答疑、专注写作。
- 记录整合资料流程与统计分析。
- JSON 备份/导入、CSV 导出、历史快照、全局搜索、PWA 离线缓存。

数据兼容：
- V6.3 使用新的本地存储键，并自动读取 V6、V5、V4、V3、V2、V1 数据。
- 升级不会主动删除旧版数据。

安装/替换：
1. 解压压缩包。
2. 将全部文件上传并覆盖 GitHub Pages 仓库根目录原文件。
3. iPhone 重新打开 App；如仍显示旧页面，可在“我的 → 工具与数据 → 刷新程序缓存”后重新加载。

重要：论文数据主要保存在设备浏览器/PWA本地。建议定期使用“我的 → 工具与数据 → 导出 JSON”备份到 iCloud Drive 或电脑。


V6.3 新增：
- 首页“今日目标”卡片可直接点按设置当天目标。
- 当天目标与“默认每日目标”分开保存；可一键恢复默认值。
- 统计分析的“单日目标完成情况”自动读取所选日期的独立目标。


V6.4 新增：
- 首页：今日完成度、今日三件事、继续上次写作、剩余工作量与健康等级。
- 写作台：今日写作路线、章节任务拆分、小节完成条件；专注结束自动弹出写作登记。
- 问题：关联小节、文献、导师修改，并显示卡点天数。
- 资料：文献研究卡增强；导师会议行动转待办；图表文件/原始数据/英文图题/正文插入管理；版本差异；送审检查中心。
- 自动兼容读取 V6.3 及更早版本本地数据。
