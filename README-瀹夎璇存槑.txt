学术猫·论文工作台｜iPhone Web App V5

V5 重点调整：
- 全模块新增统一记录时间：新建、修改时间自动精确到秒（YYYY-MM-DD HH:mm:ss）。
- 对问题解决、修改完成、待办完成、定稿检查完成、答辩准备完成等，额外记录完成/解决时间。
- 写作、会议、版本、节点仍保留“业务日期”，同时另存系统创建/修改时间，两套时间互不冲突。
- 旧 V4/V3/V2/V1 数据自动兼容迁移：旧数据原来只有日期的继续保留到日期；原版本完全没有时间字段的记录会标记为历史迁移记录，不伪造原始创建秒数。
- 章节、小节、问题、文献、导师修改、待办、会议、图表、节点、版本、定稿检查、答辩、写作记录均可看到记录时间。
- “统计”升级为：单日 / 每周 / 每月 / 年度 / 总览。
- 单日、每周、每月、年度均支持上一周期/下一周期以及日期选择器，可直接查看历史统计。
- “每月”页面会列出该月覆盖的每一周；点击任意一周即可进入那一周的完整统计。
- “总览”新增最近 12 个月历史入口，可先进入过去某个月，再查看该月某一周。
- CSV 导出新增：业务日期、创建时间、最后修改、完成/解决时间等时间列。
- V5 使用新的本地存储键并自动读取 V4 数据，避免升级覆盖旧数据。

原 V4 功能继续保留：
- 底部一级导航可横向滑动：首页 / 章节 / 问题 / 资料 / 统计 / 设置。
- 设置页集中管理论文参数、JSON 备份/导入、CSV 导出、历史快照、全局搜索和缓存。
- 支持 iPhone 添加到主屏幕、PWA 离线缓存。

推荐 GitHub 仓库：thesis-workbench
解压后将全部文件上传到仓库根目录，GitHub Pages 保持 main / (root)。

重要：论文数据保存在 iPhone 本地。建议定期在“设置 → 工具与数据 → 导出 JSON”备份到 iCloud Drive/电脑。
